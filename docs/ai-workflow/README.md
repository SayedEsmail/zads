# AI-agent workflow documents

Briefs, hand-overs and review scopes written for (and partly by) AI coding agents during the Sept 2026 production hardening of Zads. Kept as a record of how the work was scoped and verified; they are not the current product spec (that is [DOCUMENTATION.md](../../DOCUMENTATION.md)).

| File | What it is |
|---|---|
| [CODEX_IMPLEMENTATION_BRIEF.md](./CODEX_IMPLEMENTATION_BRIEF.md) | The prioritised implementation brief handed to an agent (P0 → P2). |
| [ZADS_REVIEW_AND_EXECUTION_PLAN.md](./ZADS_REVIEW_AND_EXECUTION_PLAN.md) | Independent review of that brief against the real code and schema (Arabic). |
| [FINAL_REVIEW_FIX_SCOPE.md](./FINAL_REVIEW_FIX_SCOPE.md) | Final code review with a fixed remediation scope (R1–R8) and verification commands. |
| [CURSOR_HANDOVER.md](./CURSOR_HANDOVER.md) | Hand-over to the next agent session: what is done, what is verified, what is still open. |
